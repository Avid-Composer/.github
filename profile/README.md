## Starting an Avid Composer Session

Before beginning, prepare the source footage, project structure, intended sequence goals, available storage, and suitable rights for the planned editorial task.

1. **Define Project:** Confirm the production scope, sequence goals, and expected output requirements.
2. **Organize Media:** Arrange approved source footage, audio, and graphics within a clear project structure.
3. **Create Sequence:** Establish a timeline that reflects the intended scene order and editorial plan.
4. **Assemble Content:** Add selected clips and audio materials to develop the initial sequence.
5. **Refine Edit:** Review pacing, transitions, and visual continuity through focused editorial adjustments.
6. **Verify Project:** Examine the completed sequence and retain project resources according to work procedures.

**Data safety note:** Preserve original source media and maintain suitable backups before making substantial editorial changes. Use only materials for which you have appropriate rights and authorization.
